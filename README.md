# 5G NR Physical Layer Simulator

A Python-based simulation and performance analysis tool for
key 5G New Radio (NR) physical layer concepts.

## Planned Features

- Digital modulation (QPSK, 16-QAM, 64-QAM)
- OFDM transmitter and receiver
- AWGN wireless channel simulation
- Bit Error Rate (BER) analysis
- Block Error Rate (BLER) analysis
- Throughput and performance visualization

## Technologies

- Python
- NumPy
- SciPy
- Matplotlib
- Pytest
